# Machine Learning

Planned ML deliverables:

1. shared feature definition with a strict prediction-time cutoff;
2. Isolation Forest process anomaly model;
3. Logistic Regression quality-risk baseline;
4. XGBoost or LightGBM comparison model;
5. time-based train/validation/test evaluation;
6. stored model name, version, metrics, and ranked contribution factors.

Quality results and any post-test measurements are forbidden as prediction inputs.
